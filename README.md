# Курс «Системная инженерия»

М.1.1.8, магистратура 09.04.02 «Информационные системы и технологии», СГТУ имени Гагарина Ю. А.

Курс рассчитан на **один семестр и 16 занятий**

Студент учится принимать и защищать инженерные решения, проходя цикл:

**Проблема → границы системы → цели → требования → архитектура → выбор реализации → проверка → эксплуатация → изменение.**

Общий кейс лекций и вводных разборов на семинарах — городская или кампусная система умной парковки. Команды применяют изученные приёмы к своим проектам, рассматривая программное обеспечение, оборудование, данные, людей и процессы как части системы.

Четыре небольшие лабораторные работы завершаются короткими защитами. Индивидуальное задание проверяет личное понимание, а итоговая защита связывает уже подготовленные артефакты и проверяет реакцию на изменение условий.
